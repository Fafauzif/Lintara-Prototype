# Station surface

`StationScene` is the default export of `StationScene.tsx` and consumes the exact shared `SceneProps` contract. The host must supply a nonzero height. Props are read through a ref and may change without reconstructing the renderer. `clock.current` is the sole timeline input.

Selection uses stable tenant IDs and vacant unit IDs, gate `G1`, train `TRAIN1`, hall zone `ZHALL`, platform zones `ZPLATFORM1` / `ZPLATFORM2`, and the shared `AD1` / `AD2` / `AD3` screen IDs. `onPlace` fires only for units passing the shared authoritative `canPlace` validation. Optional `placementSize` and `movingId` support exact footprint previews and moving an existing shop. Click or drag-and-drop chooses a candidate; the application owns the confirmation transaction.

The authored hall is at y=1, the rail/platform level at y=0; the main circulation spine is z=-2.8; fare gates sit near x10,z4 and stairs near x8,z6. Commercial coordinates come from the shared data. Storefront footprints are small 3×2, medium 4×3, and large 6×4 with frontage alignment and quarter-turn orientation. These are demonstration dimensions, not surveyed measurements.

The renderer and simulation consume the same `shopTransform` pose/front/inside helper, eliminating independent entrance placement. Footprint definitions come from planning. Fare-gate lane x12 and the elevated transfer footbridge remain clear of modeled walkers. Static wayfinding, vacancy labels, shop slogans, canvas accessibility copy and active/default ad copy update with EN/ID language. Campaign archive, timing, creative and tenant category all affect the same screen surface.

When a snapshot supplies its optional `trains` array, platform 0 uses `TRAIN1` and platform 1 uses `TRAIN2`. Both groups share the same geometry/material ownership, while doors and poses update independently from their own approach/dwell/departure phase. Missing platform entries hide that train. Legacy snapshots and the static CPU illustration retain the original single `train` field/group; the second group starts hidden. Rendering a second train does not create passengers or change model demand.

References inspected directly: owner photographs July 2026 commercial hall and gate/ad view, December 2024 hall/truss/rail glimpse. Preserved visual anchors are pale pitched triangular trusses, high louvers/daylight roof sheets, cream tiled floor, charcoal bands, yellow tactile routes, edge storefronts, broad advertising faces and metal gate bank. Exact dimensions, transfer footbridge, fixtures and fictional shop identities are authored. This is KRL Sudirman, distinct from the neighboring BNI City / Sudirman Baru station.

Repeated static geometry is merged by shared material. Pedestrians use two dynamic InstancedMesh pools. The displayed samples are representative: 720 maximum at high, 420 balanced, 180 low; rendering never changes model counts or financial metrics. Agent ID/color and the shared snapshot preserve deterministic movement. No passenger React components or per-frame state changes occur. GPU updates suspend when the host/document is hidden. All owned geometry, materials and textures are disposed on unmount; tenant geometry is disposed on plan changes.

Canvas supports drag orbit, right-drag pan, scroll/pinch zoom, arrow-key pan, +/- zoom, and R reset. Selecting through the outer DOM unit list follows the same focus identity. Reduced-motion preference removes camera tweens and passenger bob. WebGL creation/context failures report `onError`; successful first rendering reports `onReady` draw calls and triangles.
