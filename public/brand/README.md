# Lintara identity assets

Original offset-corridor symbol and outlined wordmark, created for this implementation. This independent brand does not imply ownership or endorsement by a rail operator.

Use `svg/lintara-horizontal-primary.svg` on light backgrounds. Use `reverse-white` on navy, `mono-navy` for single-colour print, and `symbol-primary` for the favicon. SVGs contain actual paths with no embedded raster or live-font dependency.

Clear space: at least 14/104 of the symbol canvas on every side of the artwork. Minimum recommended size: horizontal 128 CSS pixels or 28 mm in print; symbol 24 CSS pixels. Favicons include 16 and 32 pixels as intentional browser exceptions.

Never stretch, recolour, add effects, remove a piece, crowd the clear space or place the full-colour logo over photography without a clear light field.

Authoritative palette and typography: brand-tokens.json. Text uses Arial, sans-serif and system fallbacks. The fixed wordmark uses outlined DejaVu Sans Bold glyphs with custom tracking. Font provenance and license are included. No standalone font binaries are redistributed.

PNG backgrounds are fully transparent. Favicon includes PNG sizes, SVG and a multiresolution ICO. Vector source and generators live in tools/brand-assets.py and tools/brand-raster.mjs.
