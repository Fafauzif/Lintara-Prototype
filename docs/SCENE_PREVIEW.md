# Station preview

The mobile/fallback SVG and WebP are an original CPU depth-buffer projection of the actual authored station geometry and baseline simulation snapshot at 1460 seconds (07:24:20 WIB). Generated by tools/scene-preview.ts with Three.js matrix projection, explicit triangle rasterization, native canvas and Sharp. The SVG is an accessible wrapper around that original raster illustration, while WebP is the lightweight application asset. The roof/wall cutaway is enabled. The scene fixtures, train, passengers, unit footprints and tenant category props are imported directly from the same source builders as the interactive model.

This is an original model illustration, not a browser screenshot. It does not establish successful WebGL initialization, interaction, frame rate, GPU-memory behavior, or application layout. Browser preview was blocked by the execution environment and was not bypassed.

Rebuild from the project root with: node --import tsx tools/scene-preview.ts (the primary runtime dependency environment variables must be present).

Projected faces: 25800; baseline present: 119; time: 1460.
