# Station preview

The bundled SVG and WebP illustration assets are the unchanged original CPU depth-buffer projection of the authored station geometry and normal-demand baseline simulation snapshot at 1460 seconds (07:24:20 WIB). Generated by tools/scene-preview.ts with Three.js matrix projection, explicit triangle rasterization, native canvas and Sharp. The SVG is an accessible wrapper around that raster illustration. Its cutaway and Hall camera (zoom 1.5) document the earlier illustration; they do not represent v1.3's new responsive camera framing or application layout. Runtime mobile/fallback planning uses the live Canvas2D map. The scene fixtures, train, passengers, unit footprints and tenant category props are imported from the shared source builders.

This is an original model illustration, not a browser screenshot. It does not establish successful WebGL initialization, interaction, frame rate, GPU-memory behavior, or application layout. Browser preview was blocked by the execution environment and was not bypassed.

Rebuild from the project root with: node --import tsx tools/scene-preview.ts (the primary runtime dependency environment variables must be present).

Projected faces: 30239; baseline present: 185; time: 1460.
